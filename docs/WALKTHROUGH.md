## 1. Підключені GitHub Skills

У каталог `.agents/skills/` середовища розробки успішно завантажено та розгорнуто 4 зазначені репозиторії скілів:
1. **`impeccable`** ([github.com/pbakaus/impeccable](https://github.com/pbakaus/impeccable)) — стандарти преміального візуального дизайну, типографіки, мікроінтеракцій та компонентної структури.
2. **`next-dev-loop`** ([github.com/vercel/next.js](https://github.com/vercel/next.js)) — скіл Next.js для автономної валідації та оптимізації маршрутів у середовищі розробки.
3. **`ui-ux-pro-max-skill`** ([github.com/nextlevelbuilder/ui-ux-pro-max-skill](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill)) — розширений набір скілів UI/UX: дизайн-система, токени кольорів, стилізація Tailwind CSS, компоненти shadcn/ui.
4. **`Anthropic-Cybersecurity-Skills`** ([github.com/mukul975/Anthropic-Cybersecurity-Skills](https://github.com/mukul975/Anthropic-Cybersecurity-Skills)) — база знань з кібербезпеки: захист JWT, безпека API, запобігання Broken Object Level Authorization, валідація OAuth2 та CORS.

## 2. Бекенд: База даних та Автентифікація

### Нові ORM-моделі SQLAlchemy (`app/models/`):
* `User` (`app/models/user.py`) — користувачі, паролі (bcrypt), ролі (`user`, `admin`), Google OAuth ID, персональні вподобання (`preferences`).
* `Source` (`app/models/source.py`) — медіаджерела, рейтинги довіри, білі та чорні списки.
* `Article` (`app/models/article.py`) — агреговані статті, заголовки, тексти, Trust Score, вердикти.
* `Bookmark` (`app/models/bookmark.py`) — збережені новини користувача.
* `VerificationHistory` (`app/models/history.py`) — хронологія фактчекінгових запитів користувача.
* `AnalysisReport` (`app/models/analysis.py`) — детальний розбір XAI.
* `FactCheckClaim` (`app/models/claim.py`) — база спростувань фактчекерів.

### Нові API Ендпоінти (`app/api/v1/endpoints/`):
* `/auth/register` — реєстрація з автопризначенням ролі `admin` першому користувачеві.
* `/auth/login` — видача Access (JWT) та Refresh токенів.
* `/auth/refresh` — оновлення сесії.
* `/auth/me` & `/auth/me/preferences` — профіль та налаштування категорій.
* `/auth/google` — підтримка Google Identity OAuth.
* `/bookmarks` — збереження та видалення закладок.
* `/history` — отримання та очищення історії фактчекінгу.
* `/sources` — керування джерелами з контролем доступу (RBAC для admin).

## 3. Фронтенд на Next.js (`frontend/`)

Ініціалізовано повнофункціональний клієнтський застосунок на **Next.js 16.3+ (App Router, TypeScript, Tailwind CSS, Lucide icons)**:
* `src/context/AuthContext.tsx`: глобальний стан автентифікації користувача.
* `src/components/Header.tsx`: динамічний хедер, який адаптується під гостя (кнопки Вхід/Реєстрація) або авторизованого користувача (аватар, закладки, історія, адмін-панель, вихід).
* `src/components/TrustBadge.tsx`: колірні індикатори достовірності (Verified, Caution, High Risk).
* `src/components/NewsCard.tsx`: картка новини з інтерактивним додаванням у закладки.
* **Сторінки:**
  - `/` — Головна стрічка з фільтрацією за категоріями, рівнями довіри та пошуком.
  - `/verify` — Сторінка інтерактивної перевірки новин (URL або текст) з детальним XAI розбором.
  - `/login` та `/register` — Форми авторизації.
  - `/bookmarks` — Перегляд збережених новин.
  - `/history` — Персональна історія перевірок.
  - `/admin/sources` — Панель модерації джерел для адміністраторів.
